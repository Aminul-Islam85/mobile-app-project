This mobile application was built using the following features & technologies:
•	React Native (with Expo) – Core framework for building the cross-platform mobile application using JavaScript.
•	Expo Go – Simplified development workflow, testing, and deployment tool for React Native apps.
•	React Navigation – Enables stack-based and tab-based navigation across screens (e.g., Home, Match Details, Top Scorers, Standings).
•	Tailwind CSS (via NativeWind) – Utility-first styling for consistent and responsive UI design.
•	API-Football (via API-football) – Provides real-time football data (fixtures, scorers, league standings).
•	Firebase Authentication – Enables secure user sign-up/sign-in functionality.
•	Date-fns – Lightweight date utility library for formatting and calculating match-related dates.
•	React Native Picker Select – Dropdown selection for filtering fixtures by league.
•	React DatePicker – Date selection on web platform.
•	Expo Push Notifications (planned) – Live game alerts. 
•	League standing and top scorer is for 2024 season. 2025 is not updated yet in the API. It is designed for English premier league only now.
